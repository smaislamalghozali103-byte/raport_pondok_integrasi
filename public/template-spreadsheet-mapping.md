# Mapping Spreadsheet Raport Pondok Modern Al-Ghozali

Gunakan tabel Markdown berikut untuk menghubungkan Spreadsheet ke setiap kelas.

| KELAS | SPREADSHEET ID/URL | SHEET |
|---|---|---|
| 1A | https://docs.google.com/spreadsheets/d/CONTOH_ID_1/edit | Rekap |
| 1B | https://docs.google.com/spreadsheets/d/CONTOH_ID_2/edit | Rekap |
| 2A | CONTOH_ID_3 | Rekap |

## Catatan

- **KELAS** harus sama dengan ID/kode/nama yang ada di Master Kelas.
- **SPREADSHEET ID/URL** boleh berupa ID Google Spreadsheet atau URL lengkap.
- **SHEET** opsional. Jika dikosongkan, sistem menggunakan "Rekap".
- Jangan memasukkan PIN, password, service-account key, atau data rahasia ke file ini.
