# Raport Integrasi Firebase — V8.9

## Fokus
Admin Master & Monitoring.

### Admin Panel
`/admin` sekarang menyediakan:
- Ringkasan operasional
- Kelas & Spreadsheet ID/URL
- Tes koneksi Google Sheets
- Impor siswa + deteksi struktur Rekap
- Master Guru dan status aktif/nonaktif
- Master Mata Pelajaran dan status aktif/nonaktif
- Daftar siswa per kelas
- Monitoring batch nilai dan status arsip Drive

### Firebase
Semua route monitoring/admin memakai Firebase Admin SDK. Route Supabase lama untuk monitoring tidak lagi dipakai.

### Import Rekap
Admin memilih kelas lalu **Impor Rekap**. Sistem membaca sheet yang dikonfigurasi, mendeteksi kolom siswa/mapel secara fleksibel, menyimpan siswa ke `students`, dan layout ke `rekap_layouts`.

### Keamanan
Admin tetap dikontrol melalui `ADMIN_TEACHER_IDS`. Jangan masukkan private key Google/Firebase ke frontend.
