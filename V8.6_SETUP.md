# V8.6 — Sinkronisasi Nilai ke Google Sheets

V8.6 melanjutkan V8.5 dengan alur:
`Simpan nilai → Firestore → sync_queue → Google Sheets/Rekap`.

## 1. Environment
Tambahkan ke `.env.local`:
- `FIREBASE_PROJECT_ID`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY`
- `SESSION_SECRET`
- `SCHOOL_YEAR`
- `GOOGLE_CLIENT_EMAIL`
- `GOOGLE_PRIVATE_KEY`

Service account Google harus diberi akses **Editor** ke setiap spreadsheet kelas.
Jangan masukkan file JSON service-account ke repository.

## 2. Import master
```bash
npm install
npm run import:master:firebase
```

## 3. Daftarkan Spreadsheet kelas
Login sebagai guru, lalu panggil endpoint:
`POST /api/admin/classes/import-rekap`

Body:
```json
{
  "classId": "ID_KELAS",
  "spreadsheetId": "ID_SPREADSHEET",
  "sheetName": "Rekap",
  "schoolYear": "2026-2027"
}
```

Endpoint membaca `Rekap`, mendeteksi siswa dan layout secara fleksibel, mengimpor siswa ke Firestore, menyimpan `spreadsheetId` pada `classes`, dan menyimpan `rekap_layouts`.

## 4. Sinkronisasi
Setelah V8.5 menyimpan nilai, panggil:
`POST /api/sync/queue`
```json
{ "batchId": "ID_BATCH" }
```

Sistem akan:
1. mengambil spreadsheetId dari kelas;
2. membaca `Rekap`;
3. mendeteksi kolom mapel tanpa hard-code posisi;
4. mencocokkan siswa dengan NISN → NIS → nama;
5. menulis nilai ke sel mapel yang sesuai;
6. memperbarui `grades`, `grade_batches`, dan `sync_queue`.

Status:
- `MENUNGGU`
- `DIPROSES`
- `SELESAI`
- `SEBAGIAN`
- `GAGAL`

Cek antrean guru:
`GET /api/sync/status`

## Catatan
- Rumus perhitungan, rata-rata, ranking, deskripsi, dan output raport tetap menjadi tanggung jawab workbook Google Sheets.
