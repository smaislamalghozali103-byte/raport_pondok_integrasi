# V16.0 ULTIMATE — Setup & Production Checklist

## 1. Install
`npm install`

## 2. Environment
Copy `.env.example` to `.env.local` and fill Firebase Admin, Google API service account, session secret, admin teacher IDs, and optional Drive archive folder.

Never commit `.env.local`, service-account JSON, or private keys.

## 3. Preflight
`npm run preflight`

## 4. Import master
`npm run import:master:firebase`

## 5. Build
`npm run build`

## 6. Run
`npm start`

## 7. Health
Open `/api/health`. Expected JSON has `ok: true` and `firebase: "ok"`.

## 8. Admin
Set `ADMIN_TEACHER_IDS` to the stable `ID Guru` values that may access `/admin`.

## 9. Google Sheets
Share each class spreadsheet with `GOOGLE_CLIENT_EMAIL` as Editor and configure the class `spreadsheetId` from Admin.

## 10. Google Drive
Set `GOOGLE_DRIVE_ARCHIVE_FOLDER_ID` if an existing archive root is used. Keep `AUTO_ARCHIVE_DRIVE=true` only after Sheets sync has been tested.

## 11. Production acceptance test
- Login with a test teacher.
- Register PIN once, then login again.
- Verify only authorized class/mapel appear.
- Enter a small test batch.
- Verify Firestore grade + batch + sync queue.
- Run sync and verify `Rekap` value.
- Verify Drive archive.
- Test failed sync + retry.
- Verify audit log.
- Test admin monitoring and export.
- Test logout and expired session.

## 12. Architecture
UI MASTER → server session → Firestore → sync queue → Google Sheets/Rekap → Google Drive archive.
Google Sheets remains the report calculation engine; the application does not duplicate report formulas.
