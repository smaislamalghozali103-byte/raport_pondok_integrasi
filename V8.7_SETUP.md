# Raport Integrasi — V8.7

V8.7 menambahkan **arsip otomatis Google Drive** setelah sinkronisasi nilai ke Google Sheets/Rekap.

## Alur

`Login → Input Nilai → Firestore → Sync Rekap → Snapshot Google Drive`

## 1. Environment

Selain environment V8.6, isi:

```env
GOOGLE_CLIENT_EMAIL=service-account@PROJECT.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
GOOGLE_DRIVE_ARCHIVE_FOLDER_ID=ID_FOLDER_ARSIP
AUTO_ARCHIVE_DRIVE=true
```

`GOOGLE_CLIENT_EMAIL` dan `GOOGLE_PRIVATE_KEY` dipakai oleh Google Sheets sekaligus Google Drive API.

## 2. Folder Drive

Buat satu folder utama di Google Drive, lalu **share folder tersebut ke email service account** sebagai Editor. Masukkan ID folder itu ke `GOOGLE_DRIVE_ARCHIVE_FOLDER_ID`.

Aplikasi otomatis membuat struktur:

```text
Folder Arsip Utama
└── 2026-2027
    └── [Unit/Jenjang]
        └── [Kelas]
            └── Raport Integrasi - [Kelas] - [Tahun] - [Timestamp]
```

Arsip adalah **copy/snapshot file Google Sheets** setelah nilai berhasil ditulis ke `Rekap`. Rumus dan sheet pada file sumber ikut terbawa karena file disalin melalui Google Drive API.

## 3. Automatic archive

Default `AUTO_ARCHIVE_DRIVE=true`. Jika sinkronisasi ke Sheets berhasil tetapi arsip gagal, status nilai tetap tidak dibatalkan; `grade_batches.archiveStatus` menjadi `GAGAL` dan error disimpan di `archiveError`.

Endpoint retry manual tersedia di:

`POST /api/archive/drive` dengan body `{ "batchId": "..." }`.

## 4. Firestore fields

Pada `grade_batches`, V8.7 menambahkan:
- `archiveStatus`
- `archiveId`
- `archiveName`
- `archiveUrl`
- `archiveFolderId`
- `archivedAt`
- `archiveError` jika gagal

## 5. Catatan keamanan

Jangan commit service-account JSON atau private key ke GitHub. Semua credential Google tetap di environment server/Vercel.
