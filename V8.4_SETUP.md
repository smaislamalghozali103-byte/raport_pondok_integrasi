# V8.4 — Jenjang → Kelas → Mapel → Siswa

Login V8.3 tetap dipakai. Dashboard sekarang mengambil master dari Firestore:

1. Jenjang dari `units`
2. Kelas dari `classes` sesuai jenjang
3. Mata pelajaran dari `subjects` sesuai jenjang
4. Siswa dari `students` sesuai kelas
5. Nama guru berasal dari session login

Input nilai sudah ditampilkan sebagai tabel dasar, tetapi tombol simpan/upload masih placeholder untuk tahap V8.5.

Jalankan:
npm install
