# RAPORT INTEGRASI FIREBASE — V9.0

## Fokus
V9.0 memperkuat versi V8.9 untuk pemakaian produksi:
- otorisasi guru berdasarkan penugasan aktif;
- audit log Firestore;
- retry antrean sinkronisasi;
- backup konfigurasi master melalui admin;
- monitoring batch + queue + audit;
- sinkronisasi Google Sheets tetap fleksibel terhadap layout `Rekap`;
- Google Drive archive tetap opsional otomatis.

## Koleksi Firestore tambahan
- `audit_logs`
- `teacher_assignments` (disarankan sebagai koleksi penugasan canonical)

## Endpoint baru
- `POST /api/sync/retry` — guru pemilik batch atau admin dapat memasukkan batch kembali ke antrean.
- `GET /api/admin/audit` — admin melihat audit log.
- `GET /api/admin/backup` — admin mengunduh backup JSON konfigurasi master.

## Otorisasi
Sebelum menyimpan/sinkronisasi nilai, sistem memeriksa `teacher_assignments` dengan:
`teacherId + classId + subjectId + status=AKTIF`.
Fallback `assignments` tetap tersedia untuk data lama.

## Catatan
- `spreadsheetId` tetap berasal dari dokumen `classes`.
- Jangan menaruh service-account JSON/private key di frontend atau repository.
- Isi `ADMIN_TEACHER_IDS` dengan ID guru admin.
- Pastikan service account memiliki akses Editor ke spreadsheet kelas.
