# RAPORT INTEGRASI FIREBASE — V15.0 FINAL

V15.0 adalah baseline production final dari rangkaian V8.5–V14.

## Arsitektur
UI MASTER → login Nama+PIN → Next.js server → Firebase/Firestore → Google Sheets(Rekap) → Google Drive Archive.

## Aturan utama
- Tidak ada Apps Script.
- Tidak ada Supabase pada runtime utama.
- Guru login menggunakan nama master + PIN.
- PIN disimpan sebagai bcrypt hash.
- Identitas internal memakai ID Guru.
- Semua akses Firestore sensitif melalui Firebase Admin SDK di server.
- Guru dibatasi berdasarkan teacher_assignments aktif.
- Spreadsheet memakai spreadsheetId per kelas.
- Layout Rekap dideteksi dinamis; jangan hardcode D:Y atau jumlah mapel.
- Credential Google/Firebase hanya berada di environment server.

## Setup production
1. Buat project Firebase/Firestore production.
2. Buat service account dan simpan credential hanya pada secret manager/environment.
3. Aktifkan Google Sheets API dan Google Drive API pada Google Cloud project.
4. Bagikan setiap spreadsheet kelas kepada service account sebagai Editor.
5. Isi `.env` dari `.env.example`.
6. Isi `ADMIN_TEACHER_IDS` dengan ID Guru admin.
7. Jalankan `npm install`.
8. Jalankan `npm run health`.
9. Import master: `npm run import:master:firebase`.
10. Jalankan `npm run build`.
11. Jalankan `npm start` atau deploy ke platform Node/Next.js.
12. Buka `/login`, buat PIN pertama untuk guru, lalu uji satu kelas/mapel.
