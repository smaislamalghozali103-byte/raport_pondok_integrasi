# V8.5 — Input & Upload Nilai

Fitur:
- Input nilai manual 0-100
- Upload XLSX/XLS/CSV
- Deteksi kolom NISN/NIS, Nama Siswa, Nilai
- Cocokkan siswa berdasarkan NISN terlebih dahulu, nama sebagai fallback
- Preview jumlah cocok/tidak cocok
- Simpan nilai ke Firestore
- Membuat `grade_batches`
- Membuat `sync_queue` untuk tahap Google Sheets
- Tidak menulis langsung ke Google Sheets pada saat tombol Simpan

## Jalankan

npm install
npm run dev

Buka:
http://localhost:3000/login

## Format Excel yang direkomendasikan

| NISN | Nama Siswa | Nilai |
|---|---|---:|
| 123456 | Ahmad | 85 |
| 123457 | Budi | 90 |

Nama kolom boleh bervariasi seperti:
- NISN / NIS
- Nama / Nama Siswa
- Nilai / Nilai Akhir / Score

Catatan:
- Data siswa harus sudah ada di collection `students`.
- Tahap sinkronisasi `sync_queue` ke Google Sheets belum dijalankan pada V8.5.
- `spreadsheetId` kelas akan digunakan pada tahap V8.6.
