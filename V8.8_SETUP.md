# Raport Integrasi Firebase — V8.8

## Fokus
Panel Admin untuk mengatur Spreadsheet ID Google Sheets per kelas.

## Akses admin
Login menggunakan sistem Nama Guru + PIN yang sama. Tambahkan document ID guru admin ke:

`ADMIN_TEACHER_IDS=ID_GURU_1,ID_GURU_2`

Jangan gunakan nama guru; gunakan ID dokumen `teachers/{teacherId}`.

## Google Sheets
Setiap kelas memiliki:
- `spreadsheetId`
- `spreadsheetSheet` (default `Rekap`)

Admin dapat mengisi ID atau URL Google Sheets di `/admin`, menyimpan, lalu menekan **Tes**.

Spreadsheet harus dibagikan ke `GOOGLE_CLIENT_EMAIL` sebagai Editor.

## Catatan keamanan
Semua akses Firebase Admin dan Google API berjalan di server. Jangan taruh private key di browser/frontend.

## Alur
Login → /admin → isi Spreadsheet per kelas → Tes → Simpan → guru input nilai → Firestore → sync queue → Google Sheets → Drive archive.
